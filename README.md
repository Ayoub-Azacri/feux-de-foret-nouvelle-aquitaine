# feux-de-foret-nouvelle-aquitaine

Projet d'analyse et de modélisation décisionnelle pour la prévention des feux de forêt en région Nouvelle-Aquitaine (Saison feux 2027), à destination de la Direction du SDIS 33.

## Contexte du projet

* Établissement : HETIC - Promotion MD5 (2026-2027)
* Module : UE01.A - Modélisation et pipelines de données
* Enseignante : Marine PROST
* Région d'étude : Nouvelle-Aquitaine (focus Gironde / SDIS 33)
